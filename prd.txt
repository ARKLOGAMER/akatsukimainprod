# 6 — REMOTE SUPABASE REST ENDPOINTS (NO SDK)

### Get all events

```
GET /rest/v1/events?select=*
```

### Get event detail

```
GET /rest/v1/events?id=eq.<ID>&select=*
```

### Insert RSVP

```
POST /rest/v1/rsvps
```

### Count RSVPs

```
GET /rest/v1/rsvps?event_id=eq.<ID>&select=count
```

### Admin login

```
POST /auth/v1/token
```

### Admin fetch guests

```
GET /rest/v1/rsvps?event_id=eq.<ID>&order=created_at.desc
```

### Update RSVP status

```
PATCH /rest/v1/rsvps?id=eq.<RSVP_ID>
```

### Update event details

```
PATCH /rest/v1/events?id=eq.<ID>
```

### Form builder save

```
PATCH /rest/v1/form_schema?event_id=eq.<ID>
```

### Export CSV

* Edge Function uses service_role.
* Client calls:

```
GET /edge/export?id=<ID>
```

# 7 — RLS (SAFE & SIMPLE)

### Allow public read (events)

```sql
create policy "public_read_events"
on events for select to anon using (true);
```

### Allow public RSVP insert

```sql
create policy "insert_rsvp_public"
on rsvps for insert to anon
with check (
  full_name is not null
  and phone is not null
  and event_id is not null
);
```

### Admin-only write

Admins restricted via JWT role check.
